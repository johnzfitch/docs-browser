## Overview

Omarchy provides 124 commands organized into functional categories. All commands follow the `omarchy-*` naming convention and are located in `/home/zack/.local/share/omarchy/bin/`.

This index provides:
- **Alphabetical listing** of all 124 commands
- **Category organization** for functional grouping
- **Cross-references** to detailed documentation files
- **Quick purpose summaries** for each command

All commands are accessible from your `$PATH` and can be run from any terminal.
